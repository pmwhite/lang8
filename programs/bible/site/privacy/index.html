Privacy policy

Last updated 20 October 2026

This policy covers the Smooth Bible app and this website.

Information

Smooth Bible collects only the information it needs to provide, maintain and improve the app and the website.

Some features use the internet, for example to load a Bible version or a recording. Those requests go to smoothbible.com or to the service that provides the content, and carry what any web request carries, such as the device’s internet address and what was asked for. Services run by others handle their requests under their own policies.

Sharing

Personal information is not sold. It may be shared with services that help run Smooth Bible, such as hosting, or where the law requires it.

Keeping and deleting

Information is kept only as long as it is needed for these purposes. Requests to see or delete it can be sent to the address below.

Changes

This policy may change. The current version is always on this page, with the date it was last updated.

Contact

Questions about this policy can be sent to contact@smoothbible.com.
