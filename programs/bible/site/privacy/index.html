Privacy policy

Last updated 18 October 2026

Data in the app

Highlights, bookmarks, notes, reading history, reading plans and settings are stored on the iPhone. They are not sent to Smooth Bible or to anyone else. The app has no accounts, analytics or advertising.

The Bible texts, the Hebrew and Greek data and the commentary are part of the app. Listen uses the iPhone’s built-in voices, and reminders are scheduled on the device.

The ESV

When the English Standard Version is read or searched, the app requests the chapter or search from Smooth Bible’s server at smoothbible.com, which gets it from Crossway’s ESV API. The request contains the book and chapter, or the search words, and like any internet request it comes from the device’s IP address.

The server does not log requests. It holds the IP address for up to one minute, to limit how many requests one device can make, and keeps a count of total requests that identifies no one. Crossway receives requests from the server, not from the device. The app also checks with the server from time to time whether the ESV is available; that request contains nothing else.

The server and this website are hosted on Cloudflare. The website uses no cookies or analytics.
