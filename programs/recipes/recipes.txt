# The recipe book: its foods, and its recipes, added as they come up. One
# thing to a line; `#` starts a comment.
#
# A food, with what is in 100 g of it (USDA FoodData Central figures,
# rounded; raw unless it says otherwise, dry for grains and red lentils,
# drained for tinned beans):
#
#   food KEY GROUP COLOR KCAL PROTEIN FAT CARBS FIBER  A C D E K B12 FOLATE  CA FE MG K ZN  NAME...
#
# grams for protein, fat, carbs and fiber; vitamins A, D, K, B12 and
# folate in micrograms (A as retinol activity, folate as dietary
# folate), C and E in milligrams; calcium, iron, magnesium, potassium and
# zinc in milligrams. GROUP is one of veg fruit protein dairy grain bean
# nut fat herb spice pantry; COLOR is how it looks, as rrggbb.
#
# A recipe:
#
#   recipe KEY NAME...
#   meal breakfast|lunch|dinner|snack
#   serves N
#   minutes N
#   about A LINE ABOUT IT
#   use KEY GRAMS AMOUNT...       an ingredient: its food, how much in all, and how it reads
#   extra KEY GRAMS AMOUNT...     one it is good with, and as good without
#   staple AMOUNT...              salt, pepper, water: what any kitchen has
#   step WHAT TO DO...
#
# An amount's first number is scaled with the servings.
